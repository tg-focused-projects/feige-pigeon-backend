# V1.2 多鸽购买 Mock 支付 — 前端联调指南

> 适用：测试环境（`test.soogif.com`，后端 develop V4.x）
> 测试环境状态：`PAID_PIGEON_ENABLED=true`（付费开关开）、`FG_PAY_MOCK=true`（mock 支付）
> 契约版本：V4.0/V4.1（见 `docs/contract.md`）
> 更新：2026-09-02

## 一、与真实支付的差异（前端只需知道这点）

**mock 支付 = 前端直接调 confirm 接口完成支付确认**；真实支付 = 微信 `wx.requestPayment` 拉起支付 → 微信回调后端 → 前端轮询订单状态。

```text
mock:   order → confirm(前端直调) → PAID + 发鸽
真实:   order → wx.requestPayment → 微信回调后端 → 前端轮询 orders 到 PAID → 发鸽
```

除 confirm 的调用方不同，**下单/槽位/订单查询/发鸽逻辑完全一致**——前端按本文封装，资格开通后只需切换支付分支。

## 二、联调流程（5 步）

### ① 进鸽舍 → 拉槽位
`GET /feige/pigeon/slots?openid=xx`（无 sign）

```json
{ "freeCount": 4, "maxSlots": 6, "paidEnabled": true, "mockPay": true,
  "slots": [
    { "index": 1, "roleKey": "XIAOBAI", "status": "IDLE", "paid": false },
    { "index": 2, "roleKey": "PANGDUN", "status": "EMPTY", "paid": false, "amountFen": 100 },
    { "index": 3, "roleKey": "HUIHUI", "status": "EMPTY", "paid": false, "amountFen": 300 },
    { "index": 4, "roleKey": "ASHAN",  "status": "EMPTY", "paid": false, "amountFen": 600 },
    { "index": 5, "roleKey": "LAOYOUCHAI", "status": "EMPTY", "paid": false, "amountFen": 1000 },
    { "index": 6, "roleKey": "HUALING", "status": "EMPTY", "paid": false, "amountFen": 1500 }
  ] }
```

- 空槽位（`status=EMPTY`）：展示候选角色 + 价格（`amountFen` 单位分）
- `roleKey`：XIAOBAI/PANGDUN/HUIHUI/ASHAN/LAOYOUCHAI/HUALING（小白免费，其余付费）
- `paidEnabled:false`（免费期兼容）时前端隐藏购买入口，走免费 `create`

### ② 选角色 → 下单
`POST /feige/pigeon/order`（form，请求头 `sign`）

```
openid=xx&roleKey=HUIHUI
```

```json
{ "code": 200, "data": { "orderNo": "ODxxx", "roleKey": "HUIHUI", "slotIndex": 3, "amountFen": 300, "status": "CREATED" } }
```

- 错误：`ORDER_CREATE_FAILED`(409)：开关关闭 / 角色非法(含小白) / 已拥有 / 已有 PAID 订单
- 重复下单防抖：同角色已有 PAID 订单时拒绝再下单（幂等保护）

### ③ 模拟支付确认（mock 核心步骤）
`POST /feige/pigeon/confirm`（form，请求头 `sign`）

```
openid=xx&orderNo=ODxxx&payTradeNo=（可空）
```

```json
{ "code": 200, "data": { "orderNo": "ODxxx", "roleKey": "HUIHUI", "slotIndex": 3, "amountFen": 300, "status": "PAID", "paid": true } }
```

- 对应真实支付的 `wx.requestPayment` 成功时刻；mock 模式下前端在此展示"支付成功"反馈即可
- 错误：`ORDER_NOT_FOUND` / `ORDER_STATE_INVALID` / `INVALID_SIGNATURE`
- **幂等**：重复 confirm 返回当前 PAID 状态，不重复发鸽（可安全重试）

### ④ 权益发放（confirm 自动完成）→ 入住动画
- confirm 成功即已创建对应角色鸽子（幂等）
- 前端跳鸽舍刷新 `slots`：目标槽位变为 `{ "roleKey":"HUIHUI", "status":"IDLE", "paid":true }`
- 播放入住动画（规格 15.5「入住动画」）

### ⑤ 订单历史 / 权益恢复
`GET /feige/pigeon/orders?openid=xx`（无 sign）

```json
{ "code": 200, "data": [ { "orderNo": "ODxxx", "roleKey": "HUIHUI", "slotIndex": 3,
    "amountFen": 300, "status": "PAID", "payTime": "2026-09-02 13:05:00", "createAt": "..." } ] }
```

- `data` 为**数组**（直接是订单列表，无包装字段）
- `status`：CREATED(待支付) / PAID(已支付) / REFUNDED(已退款) / CANCELLED
- 用途：订单历史页；重进小程序时查 PAID 订单补入住动画（权益恢复）

## 三、前端封装建议（为真实支付预留分支）

```js
// 统一购买入口：mock 与真实支付只差 confirm 来源
async function buyPigeon(roleKey) {
  const slots = await api.get('/feige/pigeon/slots', { openid });
  if (!slots.paidEnabled) return doFreeCreate(roleKey);   // 免费期兼容

  const order = await api.post('/feige/pigeon/order', { openid, roleKey }, { sign: true });
  if (!order.orderNo) return showError(order);            // ORDER_CREATE_FAILED 等

  if (slots.mockPay) {
    // ===== mock 支付（测试环境）：直接确认 =====
    await api.post('/feige/pigeon/confirm', { openid, orderNo: order.orderNo }, { sign: true });
  } else {
    // ===== 真实支付（资格开通后）：wx.requestPayment + 轮询 =====
    // const payParams = await api.get('/feige/pay/prepay', { orderNo: order.orderNo }); // 待实现
    // await wx.requestPayment({ timeStamp, nonceStr, package: 'prepay_id=xxx', signType, paySign });
    // await pollUntilPaid(order.orderNo);   // 轮询 GET /feige/pigeon/orders 直到 status=PAID
  }

  // 权益已发放：刷新槽位 → 入住动画
  const fresh = await api.get('/feige/pigeon/slots', { openid });
  showArrivalAnimation(fresh, roleKey);
}

// 支付状态轮询（真实支付用；间隔 2~3s，超时提示"支付结果确认中"，保留查询入口）
async function pollUntilPaid(orderNo) {
  for (let i = 0; i < 20; i++) {
    await sleep(3000);
    const orders = await api.get('/feige/pigeon/orders', { openid });
    const o = orders.find(x => x.orderNo === orderNo);
    if (o && o.status === 'PAID') return true;
  }
  return false; // 超时：提示「支付结果确认中」，保留查询入口（规格18.5）
}
```

## 四、异常态联调（规格 18.5）

| 场景 | 表现 | 前端处理 |
|---|---|---|
| 重复下单同角色 | `ORDER_CREATE_FAILED`(409) | 提示"已拥有或订单处理中" |
| confirm 重复调用 | 幂等返回 PAID | 安全重试，不重复发鸽 |
| 下单后未 confirm（模拟支付中断） | orders 里 status=CREATED | 显示"待支付"，提供重新确认入口 |
| 订单不存在 | `ORDER_NOT_FOUND` | 回到鸽舍重新选 |
| 开关关闭（免费期） | slots.paidEnabled=false | 隐藏购买入口，走免费 create |
| mock 与真实切换 | slots.mockPay 字段 | 前端据此选择支付分支，无需发版判断 |
