# 行政区划坐标表（city-coords.tsv）

## 用途

写信/认领接口在缺少精确经纬度时，按 `province` + `city` 从本表取城市中心坐标兜底，
保证信件正常起飞。查找优先级：**精确坐标 → 城市级 → 省级**（见 `CityGeoService`）。

## 格式

UTF-8，制表符分隔，无表头，`#` 开头为注释：

```
省<TAB>城市<TAB>纬度<TAB>经度
```

- 城市为空的行 = 该省省级兜底坐标（如 `广东\t\t23.13\t113.26`）
- 直辖市/特区：省级行与市级行并存（`北京\t北京\t39.90\t116.41`）

## 覆盖范围

- 31 个省级行政区 + 港澳台，全部有省级兜底
- 全国地级市/自治州/盟/地区中心坐标（约 300 条）
- 坐标取主城区中心近似值（4 位小数），数据为公开常识性数据

## 扩充方法

直接追加一行即可，重启应用生效。例如新增区县粒度：

```
广东	番禺	22.9377	113.3845
```

## 精度说明

- 城市级坐标用于**游戏化送信**的距离/时长计算，市级近似足够
- 若前端能提供精确坐标（wx.getLocation），将优先使用，本表仅作兜底
